Fusion Studio — моя система для «слияния» нескольких ИИ. Вместо того чтобы спрашивать одну модель, приложение запускает сразу несколько CLI-агентов (Claude Code, Codex CLI, Antigravity CLI и любые другие) и проводит их по конвейеру:

**черновики → перекрёстная критика → слияние → проверка → правки**

Каждый агент пишет свой вариант, затем критикует чужие, лучшие идеи собираются в один документ, и он проходит проверку. На выходе получается ТЗ, архитектура или ADR, где слабые места одной модели закрыты другими.

## Что умеет

- **Живой прогресс.** В дашборде в реальном времени видно, что делает каждый агент и как собирается итоговый документ.
- **Ваши подписки.** CLI работают на вашей машине под вашими аккаунтами. Вход и проверка агентов делаются прямо из настроек.
- **Учёт расходов.** Бюджеты на прогон и на месяц, отдельный учёт неуспешных и отменённых попыток.
- **Безопасность по умолчанию.** Приложение слушает только локальный адрес, ключи хранятся отдельно и с ограниченными правами.
- **Демо-режим** для запуска без установленных агентов.

## Стек

TypeScript, Node.js 22, монорепозиторий на pnpm, Vite для интерфейса, Playwright для end-to-end тестов. Работает на Windows, macOS и Linux.
