upkeep.kz is a project I launched as a co-founder in September 2021. There was no code, no mockups, no ready-made templates — just an idea and a blank page.

## Design

I came up with and drew the entire interface myself: structure, flows, visual style, every screen and state. It was important that the product be easy to use from the very first time — no instructions, no extra clicks.

## Frontend

I built everything the user sees: responsive pages, forms, user dashboards, the small details of interface behavior. Design and code were done by one person, so what was in the mockup made it to production without losses.

## Backend

I built the server side myself too: data, business logic, API, authentication, integrations and deployment. I paid special attention to security and stability — which is why I don't disclose technical details here.

## Result

The product was built entirely by one pair of hands — from the first idea to a working service that lives and keeps growing.
